# Filosofía del sistema

Fitlosophy no es un programa cerrado de diez semanas ni un calendario fijo. Es un sistema adaptativo para decidir qué entrenamiento conviene hacer cada día.

## Principios

1. BJJ es el deporte principal.
2. El trabajo físico debe mejorar el rendimiento y la salud, no competir con el tatami.
3. No todas las sesiones deben ser duras.
4. Se busca aumentar el volumen semanal sin aumentar de forma descontrolada la fatiga.
5. La continuidad durante meses tiene prioridad sobre un entrenamiento aislado muy intenso.
6. El peso corporal es una métrica, no el único objetivo.
7. La zona lumbar condiciona la selección y combinación de ejercicios.
8. Una sesión debe terminar con la sensación prevista: estímulo, no destrucción.

## Tres tipos de día

### Físico compatible con BJJ

Sesión corta o moderada, lejos del fallo y con bajo coste lumbopélvico.

### Físico potente sin BJJ

Sesión completa de fuerza, potencia o acondicionamiento, con capacidad para asumir mayor fatiga.

### Recuperación activa

Movimiento de baja intensidad para mejorar la recuperación, combatir el sedentarismo y mantener el hábito.

## Idea central

No se trata de entrenar menos, sino de distribuir mejor las sesiones caras y baratas para poder entrenar más semanas seguidas y con menos interrupciones.
